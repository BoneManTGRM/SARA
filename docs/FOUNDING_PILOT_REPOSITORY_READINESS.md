# $149 Public Repository Readiness Snapshot

Status: owner-review business package · no customer contacted · no offer accepted · no deployment or payment action

## The narrow opportunity

Sell one fixed-scope, owner-controlled review of one public GitHub repository for **$149**. The customer receives a concise readiness snapshot, source-linked findings, and a prioritized next-step list. Automation gathers and organizes evidence; a human owner reviews the result before anything can be delivered.

This is deliberately smaller than a penetration test, certification, remediation engagement, or private-source audit. It converts capabilities already present in SARA and NICO into a clear founding pilot without adding infrastructure cost.

## Public evidence for the problem

GitHub documents three distinct repository risks that owners need to understand:

- [Code scanning](https://docs.github.com/code-security/code-scanning/automatically-scanning-your-code-for-vulnerabilities-and-errors/about-code-scanning) analyzes a repository for security vulnerabilities and coding errors.
- [Dependency review](https://docs.github.com/code-security/supply-chain-security/understanding-your-software-supply-chain/about-dependency-review) shows dependency changes and their security impact, including known vulnerability data.
- [Secret scanning](https://docs.github.com/code-security/secret-scanning/about-secret-scanning) scans Git history for hardcoded credentials and helps identify secret sprawl.

These sources establish a real review need. They do **not** prove that customers will buy this package or that $149 is the optimal price; those remain testable assumptions.

## Fixed scope

Included:

1. One canonical public GitHub repository.
2. Public evidence inventory.
3. Code, dependency, secret-exposure, and release-control readiness summary.
4. Prioritized findings with exact public source locations.
5. Thirty-minute owner review and explicit delivery decision.

Excluded:

- private repositories, credentials, regulated data, or customer secrets;
- penetration testing or exploit validation;
- production access, code changes, remediation, or deployment;
- legal, compliance, warranty, or certification claims;
- automatic outreach, contract acceptance, payment collection, or delivery.

## Definition of done

The owner-review package is complete only when:

- the repository and requested scope pass `compileFoundingPilot`;
- evidence can be reproduced from the named public repository revision;
- every material finding has a public source location and confidence label;
- NICO output, if used, remains an automated draft until human review;
- the owner separately approves the customer, final scope, payment request, and delivery.

## Plausible route to revenue

1. The owner selects a legitimate repository owner or accepts an inbound request.
2. The owner sends the fixed public-repository intake and confirms repository-owner permission.
3. SARA compiles the request into a qualified, owner-review, or reject card.
4. The owner personally approves the scope and sends any payment request through an owner-controlled processor.
5. NICO prepares evidence; a human reviews it; the owner authorizes delivery.

At a three-hour delivery ceiling, one $149 pilot tests demand and creates a reusable, owner-controlled sample without new recurring cost. It is validation work, not a claim of profitability.
