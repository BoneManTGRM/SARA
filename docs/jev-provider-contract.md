- https://docs.typesafe.ai/model-jaggedness/jev-1.13 — numeric comparisons, timestamps, counting, indirection and adversarial content are known weaknesses. State can steer the model. All permission, freshness, revision matching, amount and state-transition decisions stay in code.

## Existing authority integration boundary

`src/kernel.ts::guardPaidModelClient` atomically reserves through the kernel-private audit store and deliberately only supports the reviewed `openai:gpt-5.6-luna:paid` route. `configureModelBudget` is owner controlled and requires positive reviewed input/output prices. Reusing that route or an unrelated standing allowance for Jev would misrepresent purpose and pricing.

`src/kernel.ts::reviewJevReallocation` exposes the actual unreserved current-month shared balance, source-state digest, outstanding obligation blockers and an exact approval target. `reallocateModelBudgetToJev` applies an authenticated, exact-target owner approval using the existing protected controls. It holds the transferred amount once in the existing financial audit authority; Luna can no longer consume it. Already spent/opening amounts and existing reservations remain held. Unreconciled paid customer obligations or active funded jobs block transfer rather than being silently cancelled. The monthly $300 ceiling is never treated as an allowance.

`src/kernel.ts::jevBudget` implements the adapter dependency seam over that same store; it is not a second ledger. Reservations bind the owner, authorized project, purpose, pinned model, question version, request digest and reviewed maximum cost. Cross-process reservations are serialized. A one-use durable dispatch claim checks current authority and emergency stop immediately before the request. `jevBudgetStatus` distinguishes total allocation, retained reservations, measured known usage and unknown charges. Allocation expires at the end of the approved month, with no rollover or automatic reload. Repeated receipts are idempotent; conflicting or out-of-bound usage requires reconciliation. Without a key, enablement and approved current allocation, no call is dispatched. Merely constructing the adapter or budget facade creates no funding authority.

For an authorized call the adapter requests a conservative reservation of 2,753 micro-USD: ceil(65,536 input tokens × 0.042 micro-USD/token). This is a reservation ceiling, not measured usage. A returned input count above that bound is rejected. Unknown charges remain null, never zero. Usage receipts contain no source text or credentials. Success does not refund the reservation; reconciliation is a kernel responsibility. Live qualification requires the reviewed capped reallocation to be applied and a server-side credential through existing secure configuration. The current available amount and whether that exact allocation has been applied are runtime facts, not assumed by this document.

## Limits and truth

The query itself needs explicit trusted external-data approval; record permission alone does not authorize sending arbitrary question text. At most eight already-authorized, unexpired public candidates are submitted, 1,500 text characters each; query max 1,000 characters, request max 20,000 bytes, response max 16,384 bytes. One concurrent request per adapter instance; the implemented atomic kernel budget enforces the shared suballocation across processes. Default total deadline five seconds, hard maximum ten seconds. No automatic retries or background work. Abort is propagated to HTTP/body reads. Cache is bounded to 128 entries and 60 seconds and binds principal, project, text/request digest, source digest, freshness, model and question version. Access is rechecked on cache reads and before dispatch. There is no persistent cache authority.

`ids` always retain ordinary-search ordering. `suggestions` are shadow only, with `promoted:false`; probabilities are never evidence verification. Synthetic transport is labeled `simulated_shadow` with `live:false`. Even an actual HTTP success stays `live_shadow` until separately evaluated. Unknown evidence, source conflicts, immutable identifiers and mandatory policy anchors belong to the canonical second-brain reducer outside the adapter.
