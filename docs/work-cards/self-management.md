Stop unjustified retry cost without concealing must-complete owner blockers. Select idle read/draft work only from current enabled contracts. Reconcile stranded work without replacement jobs. Recommend capability learning/retirement from observed failures while retaining history and exact promotion authority.

Use existing kernel invocation receipts, jobs, reservations and procedural records; no second queue or authority. The execution integration may run only reviewed read/draft capabilities with exact per-step idempotency. It must stop on missing inputs/evidence or changed identities, resume completed steps after restart, and never submit an external action. Existing effectful executors remain separately authorized.

Required proof: explicit dependency cycles rejected; required commitment before profitable discretionary work; unauthorized high-profit blocked; insignificant score changes preserve order; must-complete economic stop produces a blocker; no unknown capability selected; persisted partial plans resume without replay effects; accounting/audit preserved.
