## Launch and replay boundary

The available Railway connection cannot execute SSH. The owner supervisor therefore runs in an isolated Railway service and spawns the same credential-free worker locally. The same reviewed PR90 broker enforces count-before-generation, ordered bounded frames, six total generations/three per arm, equal partitions of the $0.15 frozen-rate reserve, cancellation and complete usage accounting. Its original local-ledger/SSH route remains unchanged. Neither route grants the candidate deployment, repository or financial authority.

Default supervisor mode is preflight only. The experimental service config explicitly selects --await-grant. On startup it verifies source, checks actual Railway source/deployment/service identities, creates a fresh 256-bit random process nonce and logs its waiting receipt. Before any provider request it requires a create-only owner grant at the fixed GitHub branch experiment/v8-owner-run-grant, file .github/sara/v8-live-owner-grant.json. That document binds the contract, reviewed commit, service, deployment, nonce, expiry (at most 15 minutes) and $0.15 ceiling. Only the owner writes that branch. Do not overwrite, delete, regenerate, or replace a consumed grant to rerun. A restart has a different nonce and cannot use the old approval. The process also consumes its nonce synchronously before connecting the worker. No automatic retries or restart policy. This is trusted-owner/application confinement, not a claim of protection against privileged code/approval modification.

The worker has no provider key and no direct network path. The supervisor alone obtains a server-side reference to the owner's existing provider key, never prints it, and accepts only the exact OpenAI endpoints/model/reasoning/token contract. Temporary local audit files are not asserted durable across deployments. Provider attempts are logged before requests; complete receipts, hash-chained audit, source identity, returned candidate proposals, final artifacts and independent verifier evidence are exported in checksummed compressed log chunks. Missing usage remains unknown and retains its reservation. Models' private reasoning text is not collected.
